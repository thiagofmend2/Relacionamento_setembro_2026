# Dashboard de Relacionamento - Setembro/2026

Dashboard gerencial interativo e independente, atualizado com os dados de setembro de 2026.

## Conteúdo

- Indicadores consolidados de atendimentos e base ativa
- Evolução mensal de janeiro a setembro de 2026
- Distribuição por canal
- Volumes por instituição
- TPR por instituição
- Principais insights comparativos com agosto
- Detalhamento dos principais motivos
- Base de ativos atualizada

## Publicação no Vercel

1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta para a raiz do repositório.
3. No Vercel, clique em **Add New > Project**.
4. Importe o repositório.
5. Em **Framework Preset**, escolha **Other**.
6. Não informe comando de build.
7. Clique em **Deploy**.

O arquivo `index.html` é a página inicial. O dashboard usa Tailwind CSS, ApexCharts, Lucide e Google Fonts via CDN, portanto precisa de conexão com a internet para carregar todos os recursos visuais.
